On GNOME and KDE, the settings app themes every program at once. On a window manager like Hyprland, Sway or i3, nothing does: GTK apps, the newer libadwaita apps, Qt apps and the cursor each read their look from a different place. This guide sets each one so they match, with commands you can copy.

## Why themes do not apply on a window manager

A desktop like GNOME runs a settings service that tells every app which theme, icons and cursor to use. A window manager does not, so each kind of app falls back to its own default:

- **GTK 3 apps** (Thunar, GIMP, Firefox's file dialogs, most older Linux apps) read `gsettings` on Wayland, and `~/.config/gtk-3.0/settings.ini` on X11.
- **libadwaita apps** (Files, Text Editor, most new GNOME apps) ignore GTK themes entirely. They only follow light or dark mode and an accent color.
- **Qt apps** (Dolphin, Kdenlive, qBittorrent, VLC) use their own style unless a platform theme plugin tells them otherwise.
- **The cursor** comes from the compositor on its own surfaces, and from each toolkit inside windows.

So "my theme does not apply" usually means one of these four is still on its default.

## Install themes where apps look for them

Use your distro's package when there is one: it puts the files where every app looks. Otherwise copy them into your home folder:

| What | Folder |
| --- | --- |
| GTK themes | `~/.local/share/themes` (older apps also read `~/.themes`) |
| Icon and cursor themes | `~/.local/share/icons` (older apps also read `~/.icons`) |
| Fonts | `~/.local/share/fonts` |

The folder name inside them is the theme's name, which is what you type in the settings below.

## GTK 3 apps: gsettings and settings.ini

Set the theme in both places, so it applies on Wayland and X11 alike. The easiest way is [nwg-look](/configs/nwg-piotr/nwg-look/), a settings window for wlroots compositors that writes both. From a terminal:

```bash
gsettings set org.gnome.desktop.interface gtk-theme 'adw-gtk3-dark'
gsettings set org.gnome.desktop.interface icon-theme 'Papirus-Dark'
gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```

and in `~/.config/gtk-3.0/settings.ini`:

```ini
[Settings]
gtk-theme-name=adw-gtk3-dark
gtk-icon-theme-name=Papirus-Dark
gtk-application-prefer-dark-theme=1
```

Restart an app to see the change. If `gsettings` reports that the schema is missing, install your distro's `gsettings-desktop-schemas` package.

## libadwaita apps: dark mode instead of a theme

libadwaita apps are designed not to load GTK themes, so changing `gtk-theme` does nothing to them. Two things do work:

- **Light or dark:** the `color-scheme` key above (`prefer-dark` or `default`).
- **Matching the GTK 3 apps to them:** use [adw-gtk3](/configs/lassekongo83/adw-gtk3/) as your GTK 3 theme. It copies the libadwaita look, so old and new apps finally match.

Some themes offer a "libadwaita" option that copies CSS into `~/.config/gtk-4.0/`. It works for colors but can break with each GNOME release; forcing a theme with the `GTK_THEME` variable breaks more often. Prefer adw-gtk3 plus dark mode.

## Qt apps: qt6ct, qt5ct and Kvantum

Qt reads its look from a platform theme plugin. Outside KDE, install **qt6ct** (for Qt 6 apps) and **qt5ct** (for older Qt 5 apps), and set this environment variable for your session:

```bash
QT_QPA_PLATFORMTHEME=qt6ct
```

Then open qt6ct (and qt5ct) and pick a style, the same icon theme as GTK, and your font. For a style that matches a GTK theme, install **Kvantum**, choose a theme in Kvantum Manager, and select `kvantum` as the style in qt6ct and qt5ct.

Where to set the variable depends on how your session starts. `~/.config/environment.d/*.conf` files (one `NAME=value` per line) are read by systemd's user manager, which sessions started through systemd or uwsm use. Otherwise, use your compositor's own setting for environment variables, as its documentation shows.

## Cursors: one theme, one size, four places

Cursors are the hardest part, because four things each read their own setting. Set the same theme name and size everywhere (here [Bibata](/configs/ful1e5/bibata-cursor/), 24 pixels):

1. **GTK apps:** `gsettings set org.gnome.desktop.interface cursor-theme 'Bibata-Modern-Classic'` and `gsettings set org.gnome.desktop.interface cursor-size 24`.
2. **Apps that use the default theme, including X11 apps under XWayland:** create `~/.icons/default/index.theme` containing:

   ```ini
   [Icon Theme]
   Inherits=Bibata-Modern-Classic
   ```

3. **Everything else:** the `XCURSOR_THEME=Bibata-Modern-Classic` and `XCURSOR_SIZE=24` environment variables, set where you set `QT_QPA_PLATFORMTHEME`.
4. **The compositor itself:**
   - Sway: `seat seat0 xcursor_theme Bibata-Modern-Classic 24` in its config.
   - Hyprland: `hyprctl setcursor Bibata-Modern-Classic 24` applies it now. Hyprland also has its own cursor format, hyprcursor, with `HYPRCURSOR_THEME` and `HYPRCURSOR_SIZE` variables; themes without a hyprcursor version fall back to the XCursor setting.
   - i3 and other X11 window managers use the `Xcursor.theme` and `Xcursor.size` lines of `~/.Xresources`.

If the cursor still changes size between windows, one of the four sizes differs.

## Icons everywhere

The icon theme follows the GTK setting for GTK and libadwaita apps, and qt6ct's "Icon Theme" tab for Qt apps. Set both to the same name. [Papirus](/configs/papirusdevelopmentteam/papirus-icon-theme/) is a safe choice: it covers almost every app, and [Catppuccin Papirus Folders](/configs/catppuccin/papirus-folders/) recolors its folders to match a Catppuccin palette.

## A worked example

One dark look everywhere, from these registry entries:

1. Install the four packages from your distro or the AUR, plus qt6ct, qt5ct and Kvantum.
2. Run the three `gsettings` commands from the GTK section, and the two cursor ones.
3. Write `settings.ini` and `~/.icons/default/index.theme`.
4. Set `QT_QPA_PLATFORMTHEME`, `XCURSOR_THEME` and `XCURSOR_SIZE`, and your compositor's cursor line.
5. Log out and back in, then pick the Qt style and icons in qt6ct and qt5ct.

For a full palette instead, such as Catppuccin, Nord or Gruvbox, pick a matching [GTK theme](/docs/gtk-themes/), [icon theme](/docs/icon-themes/) and [cursor theme](/docs/cursor-themes/), or generate colors from your wallpaper with one of the [color scheme tools](/docs/color-schemes/).

## Flatpak apps

Flatpak apps cannot see your home folder's themes. If the theme has a Flatpak version, install it; otherwise let them read your theme and icon folders, then restart them:

```bash
flatpak override --user --filesystem=xdg-data/themes:ro --filesystem=xdg-data/icons:ro
```
